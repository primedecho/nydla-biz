# NYDLA.biz theme

Paid-sponsor showcase hub and mini-sites for **nydla.biz**. Separate from the NYDLA.com association theme.

## What editors use

**Appearance → Customize → NYDLA.biz Theme**

- Brand & logo, colors, header
- Hub hero + hub showcases (1–12 cards)
- CTAs & TAC-USA path (no cart)
- Mini-site defaults + footer

**Pages → Mini-site template** for product pages (featured image + short copy + optional sponsor accent in the sidebar box).

## Install

1. Upload / deploy the `nydla-biz` theme folder to `wp-content/themes/`
2. Activate **NYDLA.biz**
3. Assign a Primary menu (optional — fallback links Hub + TAC-USA)
4. Set front page to a static page if you want editable body copy under the hub
